Template Variables

                

                    Available in both Target URL and Payload Template —
                    the same triggering event fills in both, so a URL can route on the same data the
                    body carries (e.g. https://host/hooks/$action). Every substitution is
                    a single left-to-right pass with no re-scanning, so a value that happens to
                    contain another variable's placeholder text is never expanded a second time.
                

                

                    

                        
                            
VariableExpands to

                        
                        
                            
$target_address / $ipThe IP address or CIDR the event concerns (the full host IPv6 by default, or the /48 subnet when Send normalized IPv6 (/48) is enabled).

                            
$normalized_addressAlways the /48-normalized subnet for non-whitelist bare host IPv6 bans, or $target_address otherwise.

                            
$action / $eventIP_ADD, IP_UPDATE, IP_DELETE, or TEST.

                            
$causeThe record's freeform cause, or Unknown if none was given.

                            
$group_nameThe target group's name, or empty if the event has none.

                            
$group_idThe target group's UUID, or empty.

                            
$timestampThe dispatch's Unix timestamp (seconds) — the same value CANONICAL_V1 signs and sends as X-Timestamp.

                        
                    

                

                

                    Putting a variable in Target URL's host/domain (rather than its path or query)
                    hands whoever can set that variable's source field — e.g. $cause,
                    which anyone with write access to the group can set — some influence over which
                    public host the dispatch goes to. Every dispatch still re-screens its
                    resolved URL for private/internal addresses regardless, but the safest place for
                    a variable is the path or query, not the host.
